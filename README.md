# Projeto Calculadora de Precificação

Este projeto consiste em uma **calculadora de precificação simples**, desenvolvida em Python, para praticar conceitos básicos de programação e automatização de cálculos.

A calculadora permite realizar cálculos relacionados à formação do preço de venda a partir dos valores informados pelo usuário.

## Arquivos do projeto

* `Calculadora.ipynb`: contém o código da calculadora desenvolvido em Python.
* `calculadora.sh`: arquivo utilizado para executar o programa pelo terminal.
* `.gitattributes`: arquivo de configuração do repositório GitHub.

## Código em Python

A calculadora foi desenvolvida em Python e permite realizar operações matemáticas a partir de valores informados pelo usuário.

O programa utiliza `input()` para receber os valores, realiza a conversão dos dados para números e utiliza estruturas condicionais para definir a operação que será realizada.

Entre as operações implementadas estão:

* Adição
* Subtração
* Multiplicação
* Divisão

O resultado da operação escolhida é apresentado utilizando `print()`.

O código também utiliza estruturas de repetição e/ou condicionais para controlar o funcionamento da calculadora.

## Como executar o arquivo `.sh`

O arquivo `calculadora.sh` pode ser executado pelo terminal em um ambiente Linux.

Primeiramente, é necessário dar permissão de execução ao arquivo:

```bash
chmod +x calculadora.sh
```

Depois, execute o arquivo utilizando:

```bash
./calculadora.sh
```

O programa será iniciado no terminal e poderá receber os valores e as informações solicitadas.

## Objetivo do projeto

O projeto tem como objetivo praticar conceitos básicos de programação em Python e Linux, aplicando esses conhecimentos à criação de uma **calculadora de precificação simples**.

Durante o desenvolvimento, foram praticados conceitos como:
